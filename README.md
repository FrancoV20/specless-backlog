## Flujo del tablero
Backlog → Refinement (DoR) → Ready for Development → In Progress → Code Review / PR → QA / Testing → Staging → Done (DoD)

## WIP Limits
In Progress: 4 | Code Review / PR: 3 | QA / Testing: 3 | Staging: 2

## Clases de servicio
- **Expedite:** incidentes críticos, saltan el WIP y se atienden en swarming
- **Fixed Date:** entregas con fecha comprometida
- **Standard:** historias del flujo normal
- **Intangible:** refactorización y deuda técnica
