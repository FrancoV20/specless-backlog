# Definition of Ready (DoR)

Una historia solo pasa de *Refinement (DoR)* a *Ready for Development* si cumple:

## Criterios funcionales
- [ ] Redactada como: "Como [tipo de usuario], quiero [capacidad], para [beneficio]"
- [ ] Objetivo de negocio y valor para el usuario definidos
- [ ] Cumple el checklist INVEST
- [ ] Criterios de aceptación en formato BDD/Gherkin (Dado que / Cuando / Entonces)

## Criterios técnicos
- [ ] Dependencias técnicas identificadas
- [ ] Componentes afectados definidos (Frontend, Backend, Base de datos, Infraestructura)
- [ ] Estimación de esfuerzo realizada por el equipo
- [ ] Sin bloqueos conocidos para iniciar el desarrollo

## Diseño y experiencia
- [ ] Diseños o prototipos aprobados por UX/UI
- [ ] Experiencia esperada del usuario definida
- [ ] Casos excepcionales analizados
